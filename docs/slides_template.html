Bulldog Circles

Find something to do, and people to do it with, across every Yale school.

AI friend matching · shared events calendar · opt-in dating · built on gpt-6-luna
github.com/jennayzyang-dev/bulldog-circles

The problem

About 15,000 Yale students in a dozen-plus schools, and most social life stays inside your own school.

"Who at Yale also loves F1 or EDM, is free on weekends, and is already going?" Nobody can search that today.

"Friends' friends or Facebook groups… join random group chats."
Abi, Law School

"Just close circles, friends' friends."

Finding company for one event: a few days (William: 5–10 days).

What is new

Events + people togetherA calendar of tonight's meetups and big trips, and for each one, who from Yale is going.
AI that explains matches"You both listed EDM and are going to the F1 watch party." Facts only, never invented.
Yale-only, every school@yale.edu sign-in, undergrad / grad filter, cross-school by design.

vs. Yale Connect (clubs, not people) · group chats (must already know them) · Eventbrite (no Yale crowd) · Bumble BFF / Hinge (not Yale, photo-first) · ChatGPT (knows nobody at Yale)

Safety rules live in code

  • Prompt injection: bios that say "ignore previous instructions" are hidden (planted test bio blocked 21×)
  • No leaks: agents never see emails; phone numbers and handles scrubbed
  • No invented people: every AI-returned ID checked
  • Dating opt-in both ways, blocks enforced in Python
  • Caps: 6 requests / 60k tokens per run · 18/18 tests pass
