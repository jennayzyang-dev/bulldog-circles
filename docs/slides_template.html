02 · What is new

Plans first, people next, AI explains why

1

Events + people together

A calendar of tonight's meetups and big trips, and for each one, who from Yale is going.

2

Matches with reasons

"You both listed EDM and are going to the F1 watch party." Facts both people wrote, never invented.

3

Yale-only and safe

@yale.edu sign-in, every school, chat only after a mutual yes, dating opt-in and hidden by default.

Compared with: Yale Connect (clubs, not people) · group chats (you must already know them) · Eventbrite (no Yale crowd) · Bumble BFF / Hinge (not Yale, photo-first) · ChatGPT (knows nobody at Yale)

06 · Safety

Safety rules live in code

  • Prompt injection: bios saying "ignore previous instructions" are hidden before the AI sees them
  • No leaks: agents never see emails; phone numbers and handles are scrubbed
  • No invented people: every ID the AI returns is checked
  • Dating opt-in both ways, blocks enforced in Python
  • Caps: 6 requests / 60k tokens per run · 18/18 safety tests pass
